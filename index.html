Fingadget Administrator & Developer API Reference

This documentation is strictly restricted to authenticated administrators and is invisible on the public reader UI.

1. Netlify & NeonDB Environment Variables

  • • DATABASE_URL: NeonDB PostgreSQL connection URI (postgresql://...neon.tech/neondb?sslmode=require)
  • • ADMIN_USERNAME: Administrator login username
  • • ADMIN_PASSWORD: Administrator login password

2. Prefix-Isolated NeonDB Schema (fngdgt_)

All tables (fngdgt_blog_posts, fngdgt_quick_reads, fngdgt_tech_eras, fngdgt_site_settings, fngdgt_contact_details, fngdgt_comments, fngdgt_audit_logs), views (fngdgt_vw_published_feed, fngdgt_vw_era_summary, fngdgt_vw_recent_audit_trail), triggers, and columns use the fngdgt_ prefix with idempotent cleanup at the top of sql/fngdgt_schema_and_seed.sql.

3. Public & Admin CORS REST API Endpoints (Access-Control-Allow-Origin: *)

External developers can consume the following endpoints exposed by netlify/functions/api.js:

Method Endpoint Description
GET/api/bootstrapFetch complete site state (posts, quick-reads, eras, settings, contact, logs)
GET / POST/api/postsList all blog posts or publish a new formatted blog post
PUT / DELETE/api/posts/:idUpdate or delete an existing blog post by ID
GET / POST/api/quickreadsList or create bite-sized quick-read items
GET / PUT/api/erasList or upsert Tech Era banners and accent palettes
GET / PUT/api/settingsRead or update active language (9 languages), active era, or breaking ribbon
GET / PUT/api/contactRead or update newsroom contact details
GET/api/auditFetch recent entries from fngdgt_vw_recent_audit_trail
